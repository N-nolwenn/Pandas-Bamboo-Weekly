This public access dataset (PublicDataset_ReligiousRestrictions_2007to2022) consolidates all data corrections and revisions. Small differences may exist between earlier publications and this dataset. In these cases, values in this dataset should be considered authoritative. For example, the 2014 Global Restrictions Index median score for sub-Saharan Africa is calculated as 1.5225 (and is rounded to 1.5) in this dataset. An earlier report published a value of 1.6.
